🧹 Panduan Selamat Bersihkan Data Hard Disk

3 cara paling selamat untuk musnahkan data peribadi sebelum hard disk dikitar semula.

Kandungan

  • 1. Pemusnahan Fizikal (Paling Selamat)
  • 2. Penulisan Semula Data (Software)
  • 3. Degauss / Nyahmagnet

  • 💡 Tips Keselamatan Data

🔨 Kaedah 1: Pemusnahan Fizikal

Kaedah paling selamat untuk pastikan data tidak boleh dipulihkan langsung. Sesuai untuk hard disk yang sudah rosak atau tidak digunakan.

CaraPeneranganTahap Keselamatan
Gerudi (Drill)Tebuk 2–3 lubang pada platter (cakera) guna mata gerudi 3mm–5mm⭐⭐⭐⭐⭐
Hammer + PakuPukul kuat pada platter sehingga pecah/retak⭐⭐⭐⭐
BakarBakar platter sehingga cair / rosak sepenuhnya⭐⭐⭐⭐⭐
Perhatian: Kaedah bakar tidak mesra alam dan boleh menghasilkan asap toksik. Lakukan di kawasan lapang dan patuhi peraturan tempatan.

Sesuai untuk hard disk yang masih berfungsi dan ingin didermakan / dijual semula.

HDD LLF Low Level FormatFormat aras rendahHDD masih berfungsi

🧲 Kaedah 3: Degauss (Nyahmagnet)

Guna medan magnet kuat untuk memusnahkan data pada platter.

PerkakasanPeneranganTahap Keselamatan
DegausserAlat khas untuk memusnahkan magnet pada platter⭐⭐⭐⭐⭐
Magnet neodymium kuatLap pada platter beberapa kali⭐⭐⭐
Nota: Degausser mahal (~RM500–RM2000) — sesuai untuk syarikat, bukan individu.

🔧 Kaedah 4: Pemisahan Platter + Magnet (Untuk Scrapper)

Ini kaedah yang saya gunakan untuk kitar semula hard disk — sesuai untuk penderma yang bagi hard disk rosak / lama.

  1. Buka cover hard disk guna skru T6 / T8
  2. Keluarkan platter (cakera aluminium) — hati-hati, ia tajam!
  3. Asingkan magnet neodymium (2 biji setiap hard disk) — magnet ini kuat dan boleh dijual semula.
  4. Platter + cover aluminium → kitar semula sebagai besi buruk.
  5. PCB (litar) → jual / kitar semula berasingan (kandungan emas & kuprum).
Keselamatan data: Platter yang telah dikeluarkan boleh dipatahkan / digerudi untuk pastikan data tidak boleh dibaca.

💡 Tips Keselamatan Data Tambahan

  • Jangan hanya format biasa — data masih boleh dipulihkan guna software recovery.
  • Guna encryption (BitLocker, VeraCrypt) sebelum simpan data — jika hard disk hilang, data tetap selamat.
  • Simpan hard disk di tempat selamat sebelum dimusnahkan / dikitar semula.
  • Pakai sarung tangan semasa buka hard disk — platter aluminium tajam dan boleh potong kulit.
Peringatan: Keselamatan data peribadi adalah tanggungjawab kita bersama. Jangan biarkan data jatuh ke tangan yang salah.
